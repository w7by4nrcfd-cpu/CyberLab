- في المتصفح: راجعنا لوحة التحكم على سطح المكتب، وأرسلنا اختبار Python بنتيجة 3/3 وظهرت الشروح ورسالة الزائر؛ وأرسلنا حل مختبر قيصر الصحيح وظهرت رسالة النجاح.
- راجعنا واجهة بعرض 390 بكسل داخل إطار اختبار مؤقت، واختبرنا زر قائمة الجوال. أزيل إطار الاختبار من النسخة النهائية.
- تسجيل دخول ChatGPT المنشور يعتمد على منصة Sites، ولم ندخل بيانات اعتماد مستخدم في الاختبار. اختبارات الهوية والعزل استخدمت حسابات وهمية داخل بيئة اختبار معزولة فقط.
- أداة WebMCP لقراءة التقدم مضافة مع اكتشاف الدعم، لكن اختبار تسجيلها لم يكن متاحًا لأن modelContext غير متاح في متصفح الفحص. وظائف الموقع العادية لا تعتمد عليها.

إعادة الفحص:

```sh
node tests/core.test.mjs
node node_modules/typescript/bin/tsc --noEmit
pnpm run build
node tests/worker.test.mjs
```

لا تعتبر هذه الاختبارات تدقيقًا أمنيًا شاملًا. لا ينفذ المشروع أكواد Python عشوائية ولا يختبر أنظمة خارجية.
